**System Role & Objective**

**Core Project Context & Constraints**

* **Tech Stack:** Vite, React, TypeScript, Tailwind CSS, Dexie.js (IndexedDB), and SheetJS (for XLSX/CSV export).


* **Hardware Paradigm:** The NFC reader acts strictly as a USB HID keyboard wedge. It types a 14-character hex string and hits `Enter`.


* **The Ultimate Goal (Physical App):** This web app will be packaged into a physical, installable iOS/Android app using **Capacitor.js**.
* **Strict Security Rule:** **NO CLOUD BACKEND.** 100% of data (students, scans, sessions) lives locally on the device hardware via IndexedDB/Dexie. The system of record is an exported Excel file.
