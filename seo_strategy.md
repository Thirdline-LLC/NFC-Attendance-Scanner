# SEO Strategy

## In scope
- Any public marketing or documentation pages shipped as web content.
- Source-level crawl controls and metadata for the deployed web artifact.

## Out of scope
- The NFC attendance scanner's operational kiosk routes (`/`, `/roster`, `/dashboard`), which are an internal single-device tool rather than search-targeted public content.
- API endpoints, generated native iOS/Android projects, build output, tests, and the mockup/design sandbox.

## Target audience
- School staff and volunteers operating the attendance kiosk; discovery is expected through organizational deployment rather than organic search.

## Primary keywords
- None identified; this project does not currently include a public marketing/content surface.

## Crawler assumptions
- The operational Vite application is client-rendered, but crawler visibility is not a product goal for internal kiosk screens.

## Dismissed categories
- Generic SEO enhancements for internal operational routes (per-route titles/descriptions, social cards, sitemap, structured data, and `llms.txt`) are not applicable unless a public marketing/content surface is added.
